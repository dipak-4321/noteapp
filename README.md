# 📝 Note Application

A simple and responsive Note Application built using **React.js and Vite**. This application allows users to create and manage their notes easily.

## 🚀 Features

* Create new notes with a heading and details.
* Prevent users from submitting empty notes.
* Display multiple notes on the screen.
* Delete notes when they are no longer needed.
* Simple and user-friendly interface.
* Fast development and build process using Vite.

## 🛠️ Technologies Used

* **React.js** – For building the user interface.
* **Vite** – For project setup and development.
* **JavaScript** – For application functionality.
* **CSS** – For styling the application.
* **HTML** – For structuring the content.

## ⚙️ Installation and Setup

Follow these steps to run the project on your computer.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal, usually `http://localhost:5173/`, in your browser.
